# HERFIT STUDIO
## Content and Configuration Register
**Reusable Gym Website Template**

### Purpose

This register identifies the business information that can be customized for each gym client. The current HerFit Studio information is fictional example content and should remain in place for the initial website presentation.

The website should not display demo labels or placeholder warnings. The replaceable content should be managed internally through the central configuration.

### 1. Business Identity

| Configuration field | Example value | Client customization |
|---|---|---|
| Business name | HerFit Studio | Replace with client's business name |
| Tagline | Ladies Gym, Quetta | Customize to the client's positioning |
| Logo | Existing sample branding | Replace with approved logo |
| Brand colors | Teal, rose, sage, off-white | Adapt to client's brand |
| Address | Sample Quetta location | Replace with verified address |
| Map URL | Sample/configured link | Replace with correct map link |
| Domain | Development value | Set client's production domain |

### 2. Contact Information

| Field | Required action |
|---|---|
| Phone | Replace with client's verified number |
| WhatsApp | Use the client's correct international-format number |
| Email | Add the client's official email if available |
| Social media | Add official profile URLs |
| Opening hours | Replace with confirmed hours |
| Ladies-only hours | Confirm actual operating policy |

### 3. Programs and Schedule

Replace the sample programs with the client's actual offerings, such as strength training, cardio, yoga, group classes, or personal training.

Confirm:

- Program names and descriptions
- Available days and times
- Instructor availability
- Eligibility or participation requirements
- Whether each class is currently offered

### 4. Membership Pricing

Update:

- Monthly fees
- Quarterly fees
- Admission or registration fee
- Personal training fees
- Package inclusions
- Discount terms
- Trial eligibility
- Cancellation and refund terms, if applicable

Ensure the pricing toggle and all related content use the same configuration data.

### 5. Trainer Profiles

For each trainer, confirm:

- Name and job title
- Approved photo
- Qualifications and certifications
- Specializations
- Permission to publish their information

Never invent credentials or imply a qualification that the trainer does not hold.

### 6. Testimonials

Replace the sample testimonials with genuine client-approved content when customizing a purchased website.

Confirm the text, attribution, and permission to publish. Do not represent invented reviews as genuine customer experiences.

### 7. Images and Media

Replace the sample images with suitable assets approved for the client's website.

Check image rights, consent, resolution, cropping, and alt text. Do not publish recognizable gym members without appropriate permission.

### 8. FAQs and Trial Booking

Customize the FAQs to reflect actual gym policies, fees, timings, facilities, and membership terms.

Verify that the trial form generates the correct WhatsApp message and directs inquiries to the client's number.

A WhatsApp handoff does not confirm a booking. The visitor must send the message and the gym must confirm the request.

### 9. SEO and Local Business Details

Update:

- Page title and meta description
- Canonical URL
- Social preview metadata
- Business name, address, and contact details
- Local business structured data where appropriate
- Sitemap and robots configuration

Use only verified information for client-specific structured data.

### 10. Client Acceptance

Before launching a customized website, obtain the client's approval of the business details, prices, schedule, trainer profiles, images, testimonials, contact links, and final design.
